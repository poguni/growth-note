# 행동특성 및 종합의견 작성 도우미 (EduScribe) 사용 설명서

> **선생님의 생활기록부 작성 부담을 덜어주는 AI 기반 학급 평가 작성 도우미**  
> 본 서비스는 교사 개인의 **Gemini API Key**를 활용하며, 학생의 모든 개인정보와 작성 데이터는 서버 전송 없이 **선생님의 PC/브라우저 로컬 저장소(`localStorage`)에 100% 안전하게 보관**됩니다.

---

## 🔒 핵심 보안 및 특징 (Privacy & Security)

- **100% 로컬 저장 (Local-First)**: 학생 이름, 성별, 평어 작성 내역은 외부 서버로 절대 전송되지 않습니다.
- **개인 API Key 사용 (BYOK)**: 구글 무료 Gemini API Key를 직접 등록하여 사용하므로 중앙 서버의 대기 지연 없이 빠른 응답 속도를 제공합니다.
- **교육부 기재 요령 준수**: 종결 어미(`~함.`, `~임.`, `~음.`, `~됨.`), 미래지향적 순화 표현 및 1+2학기 연속성 관리를 완벽 지원합니다.

---

## 📖 단계별 사용 방법 (Step-by-Step Guide)

### 1단계: 아이디 생성 및 로그인 (Sign Up & Login)
1. 첫 화면의 **[선생님 회원가입 (등록)]** 탭을 클릭합니다.
2. 사용할 **아이디**와 **비밀번호(영문+숫자 10자리 이상)**를 입력한 후 **[등록하기]**를 누릅니다.
3. 가입된 아이디와 비밀번호로 로그인합니다.

> 💡 **관리자(Admin) 로그인 참고**:  
> 관리자 첫 접속 시 시스템 안내에 따라 자신만의 **관리자 비밀번호**를 등록하게 됩니다. 관리자 화면에서는 교사 계정 관리 및 전체 학급 평가 진행 현황을 파악할 수 있습니다.

---

### 2단계: 새 학급 추가 (Add New Class)
1. 로그인 후 상단 메뉴의 **[학급선택]** 드롭다운 버튼을 클릭합니다.
2. **[+ 새 학급 추가]** 메뉴를 선택합니다.
3. 현재 담당하시는 학년과 반(예: `5학년 3반`, `5-3` 등)을 입력하고 **[추가]**를 누르면 해당 학급 전용 공간이 생성됩니다.

---

### 3단계: 학생 명단 업로드 (Upload Student List)
학급에 학생 명단을 등록하는 방법은 두 가지가 있습니다.

- **방법 A: 엑셀 파일 한 번에 업로드 (추천)**
  1. 좌측 메뉴 상단의 **[양식 다운로드 (.xlsx)]** 버튼을 눌러 표준 명단 템플릿을 다운로드합니다.
  2. 엑셀 파일에 학생들의 `번호`, `이름`, `성별(남/여)`을 입력하고 저장합니다.
  3. **[학생 명단 엑셀 업로드]** 버튼을 클릭하여 작성한 엑셀 파일을 선택하면 전체 학생 명단이 한 번에 등록됩니다.

- **방법 B: 전입생 수동 추가**
  1. 좌측 하단의 **학생 추가 (전입)** 입력란에 학생 이름과 성별을 입력한 뒤 **`+`** 버튼을 누릅니다.

---

### 4단계: Gemini API Key 등록 (Configure API Key)
1. 화면 우측 상단의 **[API Key]** 버튼을 클릭합니다.
2. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 발급받은 본인의 **Gemini API Key**를 입력합니다.
3. `API Key를 이 브라우저에 안전하게 저장` 항목에 체크한 후 **[저장하기]**를 누릅니다.

> 🔑 **API Key 발급 방법**:
> Google 계정으로 접속하여 무료로 1분 만에 발급 가능하며, 기본 모델로 설정된 **`gemini-3.6-flash`**를 통해 가장 빠른 속도로 문장을 생성할 수 있습니다.

---

### 5단계: 학생별 행동특성 칩 버튼 선택 (Select Keyword Chips)
1. 좌측 학생 명단에서 평어를 작성할 학생을 선택합니다.
2. 중앙의 평가 입력 창에서 3대 관찰 영역 탭을 이동하며 해당 학생의 행동 특성에 맞는 키워드 칩 버튼을 클릭합니다.
   - **인성 영역** (최대 3개 선택)
   - **학교생활 영역** (최대 3개 선택)
   - **교과학습 영역** (최대 3개 선택)
3. 선택된 키워드 칩은 눈에 잘 띄는 **Live Lime (`#7efa55`)** 색상으로 전환됩니다.
4. 필요시 하단 `특이사항 및 관찰 기록` 상자에 교실에서 실제 관찰한 구체적인 사례를 자유롭게 추가 입력합니다.

---

### 6단계: Gemini AI로 평어 만들기 (Generate Evaluation Report)
1. 우측 하단의 **목표 글자수 (200byte ~ 1000byte)** 탭 중 원하는 문장 길이를 선택합니다.
2. **`문체 스타일`** 드롭다운에서 담임교사의 성향에 맞는 스타일을 선택합니다.
   - **`담백·자연스러움 (추천)`**: 상투적인 AI 미사여구를 빼고 교실 관찰 정황 중심의 자연스러운 서술
   - **`표준·격식형`**: 전통적인 생기부 기재요령 표준 어조
   - **`칭찬·성장 강조형`**: 학생의 장점과 발전 가능성을 격려하는 따뜻한 어조
3. **[✨ Gemini AI로 평어 만들기]** 버튼을 누르면 몇 초 내로 완벽한 생활기록부 평가 문장이 생성됩니다.

---

### 7단계: 내용 수정 및 문장 다듬기 (Refine & Edit Report)
1. AI가 생성한 문장은 텍스트 상자 안에서 교사가 자유롭게 직접 수정할 수 있습니다.
2. **문장 다듬기 (윤문 기능)**:
   - 생성된 문장이 약간 딱딱하거나 AI 티가 난다고 느껴질 경우, **[🪄 문장 다듬기]** 버튼을 누르면 더욱 자연스럽고 사람이 직접 쓴 것 같은 고품질 문장으로 실시간 교정됩니다.
3. 2학기 평어 작성 시에는 1학기 평어 내용과 중복되지 않도록 AI가 문맥을 자동으로 조율합니다.

---

### 8단계: 결과물 저장 및 엑셀/JSON 내보내기 (Export & Save Results)
작성된 평어 데이터는 이동 시 자동으로 저장되며, 파일로 백업할 수 있습니다.

- **JSON 백업 파일 저장**: 상단의 **다운로드(Download) 아이콘**을 클릭하면 현재 학급의 작성 데이터 전체가 `[학급명]_행동특성_종합의견_20260730.json` 형태의 파일로 저장됩니다. 나중에 **업로드(Upload) 아이콘**으로 언제든 복원할 수 있습니다.
- **평가 결과 엑셀 내보내기**: 상단의 **[결과 저장 (xlsx)]** 버튼을 클릭하면 1학기 및 2학기 평어와 선택된 키워드가 잘 정리된 최종 엑셀 파일(`[학급명]_행동특성_평가결과_20260730.xlsx`)로 다운로드됩니다.
- **1+2학기 전체 복사**: 생활기록부 작성 시스템(NEIS 등)에 복사·붙여넣기 할 수 있도록 **[1+2학기 전체 복사]** 버튼을 제공합니다.

## ❓ 자주 묻는 질문 (FAQ)

- **Q. 다른 사람이 제 컴퓨터에서 제 학생 데이터를 볼 수 있나요?**  
  A. 로그아웃을 하시면 계정 비밀번호 없이는 어떠한 데이터도 열람할 수 없습니다.

- **Q. AI 생성이 느리거나 오류가 발생해요.**  
  A. 구글 서버 일시 요청 폭주 시 약 5~10초 후 다시 시도하시거나, API Key가 올바르게 등록되어 있는지 확인해 주세요.
