<행동특성 및 종합의견 도우미(Behavior Report Assistant)>


[프롬프트 #01] 앱의 핵심 기능 정의

1. 목표 : 초등학교 학교생활기록부의 행동특성 및 종합의견을 작성하는데 도움을 주는 앱 개발

2. 대상 : 초등학교 선생님

3. 핵심 기능
  ① 웹 앱이 아닌 윈도우 환경에서 단독으로 실행되는 앱 개발(일렉트론(Electron) 방식 : HTML, CSS, JavaScript 같은 웹 기술을 활용하여 데스크톱 애플리케이션을 개발하는 프레임워크를 의미)
  ② 첫 화면에 로그인 화면 표시 - 처음 실행할 때 아이디와 비밀번호(영어+숫자 10자리 이상), 비밀번호 재확인으로 입력 받아 프로그램 내부에 저장
  ③ 이 앱은 교사 개인이 로컬에서만 사용하는 프로그램임
  ④ 메인화면은 세로로 3단으로 구분
  ⑤ [왼쪽 패널]
    - 앱의 아이콘 및 제목 표시, 엑셀 파일로 학생 명단을 업로드
    - 엑셀 파일은 번호, 이름, 성별로 구성되어 있고 엑셀 양식을 다운 받을 수 있는 기능 필요
    - 엑셀 파일이 업로드 되면 왼쪽 패널에 학생 명단 출력
  ⑥ [가운데 패널]
    - 행동발달 영역과 세부 항목들이 표시되는 부분
    - 3가지 영역의 세부 항목들이 버튼 형식으로 나열
    - 인성 영역, 학교생활 영역, 교과학습 영역에서 각각 1~3개까지 선택할 수 있도록 함(즉, 최대가 9개임)
    - 3가지 영역 밑에는 '선생님의 추가 의견' 텍스트 상자를 만들어 선생님들이 의견을 추가로 입력할 수 있도록 해야 함
    - 맨 끝에는 '문장 길이 선택(200byte, 400byte, 600byte, 800byte, 1000byte)' 버튼과 'Gemini AI로 평어 만들기' 버튼 표시
    - 'Gemini AI로 평어 만들기' 버튼을 클릭하면 미리 설정된 페르소나와 함께 학생 정보와 선생님이 선택한 문장 길이와 항목들이 Gemini에게 전달되고, AI가 만든 문장을 받아서 오른쪽 패널에 표시해야 함
      
      [인성 영역]
        1. 자기 관리: 감정 조절, 끈기, 성실, 소신, 열정, 자기주도성, 절제, 정직, 책임감, 회복탄력성

        2. 대인 관계: 감사, 겸손, 경청, 관용, 나눔, 다양성 존중, 배려, 신뢰, 친절, 타인 존중

        3. 공동체 의식: 갈등 해결 능력, 공정, 관계지향성, 규칙 준수, 봉사, 협력, 환경/생태 감수성

      [학교생활 영역]
        1. 교우 관계 및 사회성: 갈등 중재자 역할, 뛰어난 공감 능력, 뛰어난 리더십, 모둠 활동 적극 참여, 사교적이고 유쾌함, 소외된 친구 포용, 양보 및 배려, 원만한 교우 관계, 의사소통 및 경청, 주변에 대한 관심, 친구들의 의견 존중, 협동적 문제해결

        2. 학교 생활 및 규칙 준수: 1인 1역 책임 완수, 공공물품 아껴 쓰기, 단정한 용의 복장, 솔선수범, 시간 엄수(등교/과제), 약속 준수, 정리 정돈 습관 우수, 투철한 봉사정신, 학급 규칙 준수

        3. 인성 및 기본 품성: 감정 조절 능력, 고운 말 사용, 긍정적인 마음가짐, 따뜻한 마음씨, 바른 예의, 반성하는 태도, 사려 깊은 언행, 섬세하고 다정함, 솔직함과 정직

      [교과학습 영역]
        1. 학습 태도 및 자기주도성: 경청 및 피드백 수용, 끈기와 도전 정신, 높은 과제 완성도, 높은 수업 집중도, 높은 학습 흥미와 노력, 성실한 학습 준비/과제 수행, 자기주도적 학습태도, 적절한 질문 태도 (또는 '활발한 질문')

        2. 학업 역량 및 탐구 능력: 글 내용 이해 우수, 뛰어난 관찰력, 비판적/논리적 사고력, 사물/현상에 높은 관심, 사회 보고서 작성 우수, 수학 문제해결 능력 우수, 왕성한 지적 호기심, 자료/매체 활용 우수, 학습 이해력 우수, 학습내용 정리 우수

        3. 교과별 특기 및 표현력: 과학 실험 태도 우수, 디지털 리터러시, 뛰어난 글쓰기, 역할극 적극 참여, 예술적 감수성, 적극적 발표 능력, 창의적인 표현력, 협동학습 태도 우수, 체육 신체활동 능력 우수, 미술 표현 능력 우수, 음악 표현 능력 우수
      
  ⑦  [오른쪽 패널] 
    - 각 학생별 텍스트 박스에 Gemini AI가 만든 평어가 들어감
    - 각 학생 밑에는 '다시 만들기', '문장 길이 줄이기, '문장 길이 늘리기', '삭제' 버튼을 아이콘만으로 표시

  ⑧ 화면 우측 상단에는 아래 3가지 버튼 구현
    - Gemini API Key 입력 : 사용자의 Gemini API Key를 입력 받고, 프로그램이 종료되면 자동으로 삭제, 어디에도 저장되지 않도록 함
    - Gemini Model 선택 : gemini-2.5-pro(추론) / gemini-3.5-flash(효율)
    - 엑셀로 결과 저장 : 번호, 이름, 성별, 선생님이 선택한 세부 항목, AI가 만들어 준 문장을 엑셀로 저장

  ⑨ AI가 문장을 생성하고, 선생님이 수정할 때마다 JSON 파일에 자동으로 내용을 저장
  ⑩ 다음에 프로그램을 실행하면 자동으로 JSON 파일을 읽어들여 직전까지 한 작업을 화면에 표시

## 1. 메인화면 레이아웃 최적화 제안

현재 구상하신 **세로 3단(좌-중-우) 레이아웃**도 직관적이지만, 실제 개발하여 모니터에서 볼 때 가운데 패널(90여 개의 키워드 버튼 + 텍스트 상자 + 길이 선택 + 생성 버튼)에 너무 많은 정보가 몰려 세로로 엄청나게 긴 스크롤이 생기거나 화면이 답답해질 수 있습니다.

초등 교사들의 실제 작업 동선(**학생 선택 ➡️ 평가 체크 및 의견 입력 ➡️ 결과 확인 및 수정**)에 최적화된 **'좌측 고정 + 우측 2단 분할'** 레이아웃을 대안으로 추천해 드립니다.

### 💡 추천: 하이브리드 가로·세로 분할 레이아웃

화면을 크게 좌측(1)과 우측(2)으로 먼저 나누고, 우측을 다시 상·하단으로 쪼개는 방식입니다.

* **[좌측 패널 (고정 슬림 바)]**: 학생 명단 리스트 (번호, 이름, 성별, 작성 완료 여부 체크아이콘)
* **[우측 상단 패널 (넓게 활용)]**: 행동발달 영역별 세부 항목 버튼들 (탭(Tab) 메뉴로 인성/학교/교과를 전환할 수 있게 하면 공간을 훨씬 넓고 깔끔하게 쓸 수 있습니다.) + 선생님 추가 의견 입력창
* **[우측 하단 패널 (결과 확인 영역)]**: 선택한 글자 수 버튼, 평어 만들기 버튼 ➡️ 그 바로 아래에 Gemini가 생성한 결과 텍스트 박스(수정 가능)와 초기화/길이조절/삭제 아이콘 배치.

> **이 레이아웃이 더 유용한 이유:**
> 3단 세로 레이아웃은 각 패널의 가로 폭이 좁아져서 세부 항목 버튼들의 글자가 잘리거나 줄바꿈이 심해질 수 있습니다. 반면, 이 구조는 버튼이 배치되는 공간의 가로 폭이 넓어져 선생님들이 한눈에 키워드를 읽기 훨씬 편안합니다.

## 2. 기능 명세서에서 수정 및 보완할 점

### ⑦ [오른쪽 패널] 및 작업 프로세스 보완 (중요)

* **현재 안:** "각 학생별 텍스트 박스에 Gemini AI가 만든 평어가 들어감"
* **보완 의견:** 왼쪽 패널에서 학생 명단을 업로드한 후, "현재 선택된(클릭한) 학생 한 명"에 집중하여 가운데서 체크하고 오른쪽에서 결과를 받아보는 방식이 UI/UX 관점에서 훨씬 깔끔합니다. 모든 학생의 결과 상자가 우측에 한꺼번에 나열되면 화면이 너무 무거워지고 스크롤 지옥에 빠질 수 있습니다.
* 대신, 왼쪽 학생 명단 옆에 **[생성 완료]** 같은 상태 표시(체크마크나 색상 변경)를 띄워주어, 선생님이 누굴 썼고 누굴 안 썼는지 직관적으로 알 수 있게 해주는 기능이 추가되면 좋습니다.

### ⑧ 화면 우측 상단 버튼 기능 보완

* **API Key 삭제 정책:** "프로그램이 종료되면 자동으로 삭제, 어디에도 저장되지 않도록 함" 규칙은 보안상 훌륭합니다. 다만, 프로그램을 켤 때마다 매번 긴 API Key를 복사·붙여넣기 해야 하는 점은 선생님들이 현장에서 매우 귀찮아할 수 있습니다.
* **절충안:** 일렉트론의 내장 보안 저장소나 로컬에 암호화하여 저장할 수 있는 옵션(**'API Key 기억하기' 체크박스**)을 주되, 저장하지 않고 일회성으로 쓸 사람만 종료 시 지워지도록 선택권을 주는 것이 사용자 경험(UX) 측면에서 더 친절합니다.

### ⑨, ⑩ JSON 자동 저장 기능 체계화

* **보완 의견:** 선생님이 내용을 수정할 때마다 즉시 디바이스에 쓰기(Write) 작업을 하면 앱이 미세하게 버벅거릴 수 있습니다.
* 학생을 바꾸거나(Focus Out), 텍스트 상자 입력이 끝나고 다른 곳을 클릭할 때, 혹은 30초~1분 주기로 **‘자동 저장(Debounce/Throttling 기술 적용)’** 되도록 내부 로직을 설계하겠다고 구체화해 두시면 좋습니다.
