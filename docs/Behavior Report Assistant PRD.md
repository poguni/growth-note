# 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요 (Project Overview)
* **제품명:** 행동특성 및 종합의견 도우미 (Behavior Report Assistant)
* **대상 사용자:** 대한민국 초등학교 교사
* **제품 목적:** 학기 말 및 학년말 초등학교 학교생활기록부의 '행동특성 및 종합의견' 작성 업무를 AI(Gemini API)의 도움을 받아 자동화 및 효율화함으로써 교사의 행정 업무 부담을 획기적으로 경감함.
* **주요 특징:** * 웹 기반 방식이 아닌 로컬 단독 실행형 데스크톱 애플리케이션으로 개발하여 학생 개인정보 유출 가능성을 원천 차단.
  * 현장 맞춤형 인성·학교생활·교과학습 3대 영역 세부 키워드 제공.
  * 데이터 자동 저장(JSON) 및 엑셀(Excel) 입출력 완벽 지원.

---

## 2. 기술 스택 및 구동 환경 (Technical Stack & Environment)
* **개발 프레임워크:** 일렉트론 (Electron) - HTML, CSS, JavaScript/TypeScript 기반 데스크톱 앱 프레임워크
* **운영체제(OS):** Microsoft Windows 환경 단독 실행
* **데이터 관리:** 외부 서버를 사용하지 않고 로컬 파일 시스템(JSON) 및 로컬 암호화 저장소 활용
* **연동 API:** Google Gemini API (`gemini-3.1-pro-preview`, `gemini-3.5-flash`)

---

## 3. 핵심 기능 요구사항 (Core Features)

### 3.1. 보안 및 로컬 인증 시스템
* **로컬 독점 환경:** 교사 개인이 자신의 PC에서만 독립적으로 사용하는 프로그램으로 설정.
* **초기 로그인 설정:** * 프로그램 최초 실행 시 사용자 계정(ID)과 비밀번호(영어+숫자 조합 10자리 이상) 및 비밀번호 재확인을 입력받아 로컬 내부에 안전하게 저장.
  * 이후 실행 시 해당 비밀번호를 통한 인증 후 메인 화면 진입.

### 3.2. 학생 명단 관리 (데이터 입력)
* **엑셀 업로드:** 번호, 이름, 성별 항목으로 구성된 표준 엑셀 파일(.xlsx)을 업로드하여 학생 명단을 대량 등록.
* **양식 다운로드:** 사용자가 입력 오류를 방지할 수 있도록 표준 엑셀 템플릿 파일 양식 다운로드 기능 제공.
* **상태 관리:** 학생 목록에 평어 작성 완료 여부를 직관적으로 확인할 수 있는 시각적 상태 아이콘(예: 체크마크 또는 색상 변경) 구현.

### 3.3. 행동발달 및 교과학습 평가 키워드 시스템
* 교사는 각 영역별로 최소 1개에서 최대 3개(학생당 총 최대 9개)의 세부 키워드 버튼을 선택할 수 있음.
* **[인성 영역]**
  1. *자기 관리:* 감정 조절, 끈기, 성실, 소신, 열정, 자기주도성, 절제, 정직, 책임감, 회복탄력성
  2. *대인 관계:* 감사, 겸손, 경청, 관용, 나눔, 다양성 존중, 배려, 신뢰, 친절, 타인 존중
  3. *공동체 의식:* 갈등 해결 능력, 공정, 관계지향성, 규칙 준수, 봉사, 협력, 환경/생태 감수성
* **[학교생활 영역]**
  1. *교우 관계 및 사회성:* 갈등 중재자 역할, 뛰어난 공감 능력, 뛰어난 리더십, 모둠 활동 적극 참여, 사교적이고 유쾌함, 소외된 친구 포용, 양보 및 배려, 원만한 교우 관계, 의사소통 및 경청, 주변에 대한 관심, 친구들의 의견 존중, 협동적 문제해결
  2. *학교 생활 및 규칙 준수:* 1인 1역 책임 완수, 공공물품 아껴 쓰기, 단정한 용의 복장, 솔선수범, 시간 엄수(등교/과제), 약속 준수, 정리 정돈 습관 우수, 투철한 봉사정신, 학급 규칙 준수
  3. *인성 및 기본 품성:* 감정 조절 능력, 고운 말 사용, 긍정적인 마음가짐, 따뜻한 마음씨, 바른 예의, 반성하는 태도, 사려 깊은 언행, 섬세하고 다정함, 솔직함과 정직
* **[교과학습 영역]**
  1. *학습 태도 및 자기주도성:* 경청 및 피드백 수용, 끈기와 도전 정신, 높은 과제 완성도, 높은 수업 집중도, 높은 학습 흥미와 노력, 성실한 학습 준비/과제 수행, 자기주도적 학습태도, 적절한 질문 태도
  2. *학업 역량 및 탐구 능력:* 글 내용 이해 우수, 뛰어난 관찰력, 비판적/논리적 사고력, 사물/현상에 높은 관심, 사회 보고서 작성 우수, 수학 문제해결 능력 우수, 왕성한 지적 호기심, 자료/매체 활용 우수, 학습 이해력 우수, 학습내용 정리 우수
  3. *교과별 특기 및 표현력:* 과학 실험 태도 우수, 디지털 리터러시, 뛰어난 글쓰기, 역할극 적극 참여, 예술적 감수성, 적극적 발표 능력, 창의적인 표현력, 협동학습 태도 우수, 체육 신체활동 능력 우수, 미술 표현 능력 우수, 음악 표현 능력 우수

### 3.4. 생성 조건 및 서술형 의견 입력
* **선생님 추가 의견:** 콤보박스나 버튼으로 규격화되지 않은 학생별 특이사항을 교사가 직접 텍스트로 자유롭게 가감할 수 있는 서술형 입력창 제공.
* **문장 길이 제어:** 200byte, 400byte, 600byte, 800byte, 1000byte 단위의 직관적인 선택 버튼 레이아웃 제공.

### 3.5. AI 문장 생성 엔진 (Gemini API)
* **기능 구현:** 'Gemini AI로 평어 만들기' 버튼 클릭 시, 시스템 명령어(초등 교사 페르소나, 어미 처리 등), 학생 기본 정보, 선택된 키워드, 교사 추가 의견, 대상 바이트(Byte) 길이를 조합하여 API 요청 전송.
* **출력 및 편집:** AI가 반환한 유창한 한국어 교육용 문장을 결과 텍스트 박스에 실시간 바인딩하며, 교사가 직접 타이핑하여 즉시 수정·보완할 수 있는 텍스트 편집기 기능 포함.
* **결과 제어 버튼군:** 각 결과물 하단에 아이콘 형태로 독립적인 제어 기능 배치.
  * *다시 만들기:* 동일 조건으로 AI 문장 재생성 요청.
  * *문장 길이 줄이기 / 늘리기:* 기존 문장을 기반으로 길이를 축소/확장 조절 요청.
  * *삭제:* 해당 학생의 생성된 결과물 및 선택 데이터 초기화.

### 3.6. 데이터 영속성 (백업 및 저장)
* **자동 저장 메커니즘:** 작업 중인 내용 유실을 방지하기 위해 사용자가 다른 학생을 선택하거나(Focus Out), 입력 행동이 완료되는 시점에 디바운스(Debounce) 처리를 적용하여 로컬 내 JSON 파일에 백업 보존.
* **이어 하기 기능:** 앱 재시작 시 해당 JSON 백업 파일을 자동으로 로드하여 직전 작업 상태를 화면에 그대로 복원.
* **최종 엑셀 출력:** 전체 작업 완료 후 번호, 이름, 성별, 선택 세부 항목, 최종 수정 완료된 AI 평어 문장을 포함한 종합 결과 보고서용 엑셀 파일(.xlsx) 내보내기 기능 지원.

## 4. UI/UX 및 레이아웃 요구사항 (Layout Design)

작업 능률 극대화 및 시선 분산 방지를 위해 **하이브리드 가로·세로 분할 레이아웃(좌측 슬림 패널 + 우측 2단 분할 구조)**을 적용함.

### 4.1. 전체 화면 구조 (메인 레이아웃)
1. **[G] 상단 글로벌 헤더 (Global Top Bar)**
   * 앱 타이틀 영역 우측 배치 컴포넌트:
     * *Gemini API Key 입력:* 사용자 API Key 입력 팝업 연동. '로컬 보안 기억하기' 체크박스와 '종료 시 자동 삭제' 보안 옵션 분리 제공.
     * *Gemini Model 선택:* 드롭다운 메뉴 형식으로 `gemini-3.1-pro-preview` (문장력/추론 최우선)와 `gemini-3.5-flash` (속도/가성비 최우선) 중 택일.
     * *엑셀로 결과 저장:* 최종 결과물 저장 및 익스포트 실행 버튼.
2. **[A] 좌측 슬림 패널 (Left Sidebar - 학생 명단 영역)**
   * 앱 아이콘 및 프로그램 타이틀 정착.
   * '학생 명단 엑셀 업로드' 및 '양식 다운로드' 버튼 최상단 배치.
   * 업로드 완료 시 번호, 이름, 성별과 함께 우측에 평어 작성 완료 여부(체크 아이콘/미완료 공백)가 표시되는 세로 스크롤 명단 리스트 뷰 배치.
3. **[B] 우측 상단 패널 (Right Top Main - 키워드 탭 및 입력 영역)**
   * 가로 폭을 최대로 활용하여 키워드 가독성 확보.
   * *영역별 탭 메뉴:* [인성 영역], [학교생활 영역], [교과학습 영역] 세 부문으로 탑 내비게이션 전환 처리하여 화면 복잡도 최소화.
   * 각 탭 클릭 시 하단에 세부 분류별 키워드가 토글식 선택 버튼 형태로 바둑판 정렬 배열.
   * 키워드 영역 하단에 넓은 형태의 '선생님의 추가 의견' 멀티라인 텍스트 박스 배치.
4. **[C] 우측 하단 패널 (Right Bottom Output - AI 생성 및 결과물 편집 영역)**
   * *제어 인터페이스:* 문장 길이 선택 라디오 버튼 그룹(200~1000byte) 및 'Gemini AI로 평어 만들기' 강조 버튼 수평 배치.
   * *출력 편집기:* 현재 선택된 학생의 최종 평어가 표시되는 스크롤 가능형 대형 텍스트 편집창.
   * *컴팩트 액션 툴바:* 편집창 바로 하단 또는 우측 하단에 '다시 만들기', '문장 길이 줄이기', '문장 길이 늘리기', '삭제' 작업을 수행하는 심플한 그래픽 아이콘 버튼 배치.

## 5. 예외 처리 및 제약 조건 (Exception Handling)
* **API Key 미입력 검증:** 사용자가 API Key를 입력하지 않은 상태에서 '평어 만들기' 시도 시, 상단 API Key 입력창 포커싱 및 경고 알림 표시.
* **키워드 선택 제한:** 각 대분역 영역(인성, 학교생활, 교과학습)별로 선택된 버튼의 개수가 3개를 초과하려 할 경우 사용자에게 알림 팝업 또는 툴팁을 띄우며 추가 선택 차단.
* **오프라인 대응:** 네트워크 연결이 끊긴 상태에서 API 요청이 발생할 경우 로컬 데이터 유실 없이 "네트워크 연결을 확인해 주세요"라는 예외 안내 메시지 노출.
