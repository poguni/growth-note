## 1. 프로젝트 개요 및 배경

초등학교 생활기록부의 '행동특성 및 종합의견' 난은 학생 개개인의 인성, 학교생활, 교과학습 성향을 객관적이고 긍정적인 문체로 서술해야 하는 담임교사의 핵심 교무 작업입니다. 

본 프로젝트는 교사의 평어 작성 부담을 획기적으로 줄이고, 교육부 '학교생활기록부 기재 요령' 기준을 완벽히 준수하는 고품질 평가 문장을 AI(Google Gemini)를 통해 자동 생성·편집할 수 있도록 개발되었습니다.

## 2. 시스템 아키텍처 및 기술 스택

### 2.1 Electron 데스크톱 앱 vs Web_version 웹 앱 비교

본 프로젝트는 **Electron 기반 로컬 앱**과 **순수 브라우저 구동 Web 앱(`Web_version`)** 두 가지 환경을 모두 지원하도록 설계되었습니다.

| 구분 | Electron 데스크톱 버전 | Web_version 웹 앱 버전 |
| :--- | :--- | :--- |
| **구동 환경** | Windows OS 데스크톱 앱 (Electron v42.4) | 모든 웹 브라우저 (Chrome, Edge, Safari 등) |
| **프론트엔드** | React v19, TypeScript, Vite, Vanilla CSS | React v19, TypeScript, Vite, Vanilla CSS |
| **데이터 저장소** | Node.js `fs` (`AppData/Roaming/BehaviorReport/`) | 브라우저 `localStorage` (Local-First) |
| **암호화 모듈** | Node.js `crypto` (`pbkdf2Sync`, `aes-256-cbc`) | 웹 표준 **Web Crypto API (`crypto.subtle`)** |
| **엑셀 처리** | Node.js native `dialog` + `xlsx-js-style` | HTML5 File API + `Blob` + `xlsx-js-style` |
| **AI 연동** | Main Process HTTPS 프록시 요청 | Browser Direct `fetch()` REST API 호출 |

## 3. 주요 기능 및 사용자 흐름 (Core Features)

### 3.1 사용자 인증 및 동적 관리자 보안 시스템
- **선생님 계정 가입/로그인**: 아이디와 비밀번호(영어+숫자 10자리 이상)로 등록하며, 패스워드는 SHA-256으로 해싱되어 저장됩니다.
- **최초 관리자 비밀번호 설정**: 소스 코드 내부의 하드코딩 비밀번호를 제거하여, 관리자 첫 접속 시 사용자가 스스로 안전한 관리자 비밀번호를 등록하도록 구성하였습니다.

### 3.2 학급 및 학생 명단 관리 (엑셀/JSON 입출력)
- **학급 생성/선택/삭제**: 학년과 반(예: 5학년 3반)을 등록하여 학급별 독립 데이터 관리.
- **엑셀 업로드/양식 다운로드**: 기본 템플릿(.xlsx)을 제공하며, 명단을 한 번에 읽어와 순번/이름/성별로 자동 등록합니다.
- **JSON 데이터 저장/불러오기**: 사용자의 '다운로드' 폴더에 `[학년반]_행동특성_종합의견_[날짜].json` 파일로 즉시 백업 및 불러오기 가능.

### 3.3 영역별 행동발달 키워드 선택 및 고대비 칩 디자인
- **3대 영역 구분**: 인성 영역, 학교생활 영역, 교과학습 영역으로 분류 (영역당 최대 2개 선택 제한).
- **고대비 칩 버튼 스타일**: 선택 안 됨(소프트 중립 회색 `#F1F5F9`), 선택됨(**선명한 카카오 옐로우 `#FEE500` + 딥 챠콜 `#191919` Bold**) 디자인을 적용하여 뚜렷한 시인성을 확보하였습니다.

### 3.4 Gemini AI 기반 평어 문장 자동 생성, 문체 스타일 및 문장 다듬기
- **기본 모델**: 가장 빠르고 효율적인 `gemini-3.6-flash`를 기본 모델로 지정.
- **문체 스타일 선택**:
  - `담백·자연스러움 (추천)`: AI 특유의 상투적 미사여구를 배제하고 담임교사가 교실에서 관찰한 듯 담백한 문체.
  - `표준·격식형`: 전통 생기부 표준 격식 체.
  - `칭찬·성장 강조형`: 학생의 장점과 발전 가능성을 따뜻하게 북돋우는 어조.
- **문장 다듬기 (윤문 기능)**: 생성된 평어 문장에서 AI 특유의 딱딱한 표현을 제거하고 사람이 직접 쓴 것 같은 어조로 다듬는 실시간 윤문 기능 탑재.

### 3.5 1+2학기 통합 평가 관리 및 원클릭 복사
- **1학기/2학기 탭 전환**: 2학기 평어 작성 시 1학기 평어 내용을 참고 문맥으로 자동 전달하여 문장 중복 방지.
- **1+2학기 전체 복사**: 생활기록부 입력 시스템에 바로 붙여넣을 수 있도록 1학기+2학기 합본 문장 클립보드 복사 지원.

### 3.6 관리자 대시보드 (Admin Dashboard)
- 선생님 목록 열람, 특정 교사 비밀번호 초기화(`assess1234`), 교사 삭제.
- 등록된 학급별 학생 평가 현황 테이블 조회.
- **높이 확장 및 Sticky Header**: 세로 420px~520px로 확장하고 헤더 고정 스크롤을 적용하여 10명 이상의 학생 현황을 한눈에 파악 가능.

## 4. 최근 오류 해결 및 성능 최적화 내역

### 4.1 Windows 입력 포커스 유실 버그 해결
- Chromium 대화상자 종료 후 Windows OS에서 창 포커스를 잃어 입력창이 얼어붙는 현상을 `mainWindow.blur()` + `mainWindow.focus()` 강제 실행으로 보완.

### 4.2 대한민국 표준시(KST/Asia/Seoul) 파일 저장 날짜 오류 수정
- **문제**: 기존 `new Date().toISOString()` 사용 시 UTC 시차로 인해 한국 시각 자정 이후 파일 저장 파일명에 어제 날짜(예: 7/30일 저장 시 20260729)가 생성되는 문제.
- **해결**: `Asia/Seoul` 타임존 기준 KST 날짜 변환 로직(`Intl / Asia/Seoul Date`)으로 전면 교체하여 정확하게 오늘 날짜(`20260730`)가 파일명에 기록되도록 수정.

### 4.3 상단 메뉴 레이아웃 및 제목 최적화
- 상단 앱 제목을 '행동특성 및 종합의견'으로 간소화하고, 학급선택 → 엑셀/JSON 연동 → AI 설정 → 로그아웃 순으로 직관적 재배치.

### 4.4 Gemini API 에러 메시지 한글 순화 처리
- 트래픽 폭주, Quota 초과, API Key 유효성 오류 등을 교사가 이해하기 쉬운 친절한 한글 안내문으로 변환 안내.

### 4.5 Gemini 3.6 Flash 기본 모델 설정 및 thinkingConfig API 규격 최적화
- 최신 `gemini-3.6-flash` 모델 연동 시, Google Gemini REST API v1beta 규격에 맞춰 `generationConfig` 내부에 `thinkingConfig: { thinkingLevel: 'MEDIUM' }` 및 `role: 'user'` 구조로 요청이 전송되도록 최적화하여 `Unknown name "thinkingConfig"` API 스키마 오류 해결.

### 4.6 관리자 화면 학생 명단 영역 세로 확장 및 Sticky Header
- 관리자 화면의 학생 명단 영역 높이를 420px로 확대하고 `position: sticky` 헤더를 도입하여 대규모 학급 관리를 원활히 했습니다.

## 5. 보안 아키텍처 및 GitHub/배포 안전성 점검

### 5.1 하드코딩 비밀번호 완전 제거
- 기존 소스 코드 상에 존재하던 `ADMIN_PW` 기본값을 전면 삭제하고, 사용자가 최초 접속 시 자신만의 관리자 비밀번호를 등록하는 구조로 전환.

### 5.2 브라우저 로컬 데이터 격리 구조 (Local-First)
- 모든 학생 개인정보 및 평어 데이터는 **사용자 개인 PC/브라우저 내에만 존재**합니다.
- 소스 코드를 GitHub Public으로 공개하더라도 타인의 학생 정보가 노출되거나 유출될 위험이 0%입니다.

### 5.3 GitHub Pages 배포 가이드
1. `Web_version/vite.config.ts` 파일의 `base` 설정을 저장소 이름으로 설정:
   ```typescript
   export default defineConfig({
     plugins: [react()],
     base: '/BehaviorReport/',
   })
   ```
2. GitHub Repository -> Settings -> Pages -> Source를 **GitHub Actions**로 설정하면 `git push` 시 자동 배포 완료.
